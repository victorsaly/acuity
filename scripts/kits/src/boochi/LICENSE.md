All samples in this repository are released under the **Creative Commons Zero (CC0 1.0)** license. You are free to use, modify and redistribute the samples in personal and commercial projects without attribution.

Many of the one‑shots were derived from the **TR‑808** sample set created by Edward Loveall and published in the `tidalcycles/sounds‑tr808‑fischer` repository, which is licensed CC0【490384358966562†L66-L83】. Additional 808 bass tones were synthesised using sine waves and waveshaping distortion, and the vintage kit was created by down‑sampling and bit‑crushing the original TR‑808 sounds. The hard trap kit features long, distorted 808 basses and processed percussions; the bounce kit uses clean, round 808s and crisp drums; the soulful kit uses lofi processing for vintage texture.

No attribution is required, but if you wish to credit the original TR‑808 sample library you may include the following:

> “Some samples derived from the TR‑808 recordings by Edward Loveall (CC0).”

## How to use

Import the samples into your DAW or beat maker. A sample configuration file (`beatpacks‑config.ts`) is included for developers integrating these packs into browser‑based drum machines. Replace `YOUR_GITHUB_USERNAME` in the URLs with your GitHub username or fork path.
